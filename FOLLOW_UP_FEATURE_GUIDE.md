## How the API Key Works (Your Question #2)

### One API Key, All Users Share It ✅

**Your Setup:**
```bash
# In .env
ANTHROPIC_API_KEY=sk-ant-api03-1qf_iOlyQy...
```

**How it works:**
1. Your backend server holds the API key
2. Mobile app requests: "Generate follow-ups for this response"
3. Backend makes request to Anthropic using YOUR key
4. User never sees or needs their own API key

**Security Model:**
```
User's Phone
    ↓ (sends story text)
Your Backend Server (has API key)
    ↓ (sends to Anthropic with your key)
Anthropic API
    ↓ (returns follow-up questions)
Your Backend Server
    ↓ (returns to user)
User's Phone (shows questions)
```

**Key Points:**
- ✅ Users don't need Anthropic accounts
- ✅ You pay for all API usage (then charge premium users)
- ✅ You control what prompts go to the API
- ✅ More secure (API key never leaves your server)
- ⚠️ You absorb the cost (but can limit via premium tier)

**Cost Control:**
```javascript
// You can limit free users
if (!isPremiumUser) {
  return res.status(403).json({
    error: 'Follow-up questions require Premium',
    upgrade: true
  });
}

// Or limit frequency
if (followUpCount > 10 this month) {
  return res.status(429).json({
    error: 'Monthly follow-up limit reached'
  });
}
```

## Current Data Storage Model (Your Question #3)

### How It Works Now ⚠️ (Not Ideal)

**When user answers original prompt:**
```sql
INSERT INTO prompt_responses (
  user_id,
  prompt_id,
  prompt_text,
  response_text,  -- "I remember learning to ride a bike..."
  created_at
) VALUES (...);
```

**When user answers a follow-up:**
```javascript
// Backend appends to original response
const updatedResponse = existingResponse + '\n\n' + followUpAnswer;

UPDATE prompt_responses
SET response_text = $1  -- Now contains BOTH answers
WHERE id = $2;
```

**Result in database:**
```
response_text: "I remember learning to ride a bike when I was 7.

My dad helped me. He held the seat and ran alongside me.

It took about a week. I fell a lot but kept trying."
```

**Problems:**
- ❌ Can't tell which part is original vs follow-up
- ❌ Can't track which follow-up questions were asked
- ❌ Can't show Q&A pairs separately in UI
- ❌ Loses context of which question prompted which answer

## Recommended Data Storage Model

### Better Approach: Separate Follow-Up Records

**Database Schema Change:**
```sql
-- Add to prompt_responses table
ALTER TABLE prompt_responses ADD COLUMN is_follow_up BOOLEAN DEFAULT FALSE;
ALTER TABLE prompt_responses ADD COLUMN parent_response_id UUID REFERENCES prompt_responses(id);
ALTER TABLE prompt_responses ADD COLUMN follow_up_question TEXT;

CREATE INDEX idx_prompt_responses_parent ON prompt_responses(parent_response_id);
```

**Data Structure:**
```
Original Response (id: abc-123):
├─ prompt_text: "Tell me about learning to ride a bike"
├─ response_text: "I remember learning to ride a bike when I was 7..."
├─ is_follow_up: FALSE
└─ parent_response_id: NULL

Follow-Up Response 1 (id: def-456):
├─ prompt_text: NULL
├─ response_text: "My dad helped me. He held the seat and ran alongside me."
├─ is_follow_up: TRUE
├─ parent_response_id: abc-123
└─ follow_up_question: "Who helped you learn to ride?"

Follow-Up Response 2 (id: ghi-789):
├─ prompt_text: NULL
├─ response_text: "It took about a week. I fell a lot but kept trying."
├─ is_follow_up: TRUE
├─ parent_response_id: abc-123
└─ follow_up_question: "How long did it take?"
```

**Benefits:**
- ✅ Each Q&A pair is separate
- ✅ Can show conversation thread in UI
- ✅ Can track which questions users answer vs skip
- ✅ Can export as structured conversation
- ✅ Better for AI Persona (knows the flow)

## How Follow-Ups Link to Prompts (Your Question #4)

### Current Linking Structure

```
Daily Prompt (prompts table)
    ↓
Original Response (prompt_responses)
    ├─ has prompt_id (links to daily prompt)
    ├─ has response_text (user's story)
    └─ Triggers AI to generate follow-ups
         ↓
Follow-Up Questions (generated by AI, not stored!)
    ↓
User answers one
    ↓
Follow-Up Response (appended to original response_text)
    └─ Loses connection to which question it was!
```

### Recommended Linking Structure

```
Daily Prompt (prompts table)
│
├─ Original Response
│   ├─ id: abc-123
│   ├─ prompt_id: daily-prompt-1
│   ├─ response_text: "Main story..."
│   └─ is_follow_up: FALSE
│
├─ Follow-Up Response 1
│   ├─ id: def-456
│   ├─ parent_response_id: abc-123 ← Links to original
│   ├─ follow_up_question: "Who helped you?" ← Stores the question!
│   ├─ response_text: "My dad..."
│   └─ is_follow_up: TRUE
│
└─ Follow-Up Response 2
    ├─ id: ghi-789
    ├─ parent_response_id: abc-123 ← Links to original
    ├─ follow_up_question: "How long did it take?"
    ├─ response_text: "About a week..."
    └─ is_follow_up: TRUE
```

**Querying the full story:**
```sql
-- Get original + all follow-ups
SELECT * FROM prompt_responses
WHERE id = 'abc-123' OR parent_response_id = 'abc-123'
ORDER BY created_at ASC;
```

### Phase 2: Mobile API Service (30 minutes)

**Add to `expo-mobile/src/services/api.js`:**

```javascript
// Generate follow-up questions
async generateFollowUpQuestions(token, question, response) {
  const apiResponse = await fetch(`${API_URL}/api/prompts/generate-followups`, {
    method: 'POST',
    headers: getHeaders(token),
    body: JSON.stringify({ question, response }),
  });

  if (!apiResponse.ok) throw new Error('Failed to generate follow-ups');
  const data = await apiResponse.json();
  return data.followUpQuestions;
}

// Submit follow-up response
async submitFollowUpResponse(token, parentResponseId, followUpQuestion, responseText) {
  const response = await fetch(`${API_URL}/api/prompts/respond`, {
    method: 'POST',
    headers: getHeaders(token),
    body: JSON.stringify({
      promptId: null,
      response: responseText,
      isFollowUp: true,
      parentResponseId,
      followUpQuestion
    }),
  });

  if (!response.ok) throw new Error('Failed to submit follow-up');
  return response.json();
}

// Get follow-ups for a response
async getFollowUps(token, responseId) {
  const response = await fetch(`${API_URL}/api/prompts/response/${responseId}/followups`, {
    method: 'GET',
    headers: getHeaders(token),
  });

  if (!response.ok) throw new Error('Failed to get follow-ups');
  return response.json();
}
```

import React, { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity, StyleSheet } from 'react-native';

export default function FollowUpAnswerScreen({ route, navigation }) {

      ]);

      Alert.alert('Error', error.message);
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <View style={styles.container}>
      <TouchableOpacity onPress={() => navigation.goBack()}>
        <Text style={styles.backButton}>← Back</Text>
      </TouchableOpacity>

      <Text style={styles.originalPrompt}>Original: {originalPrompt}</Text>
      <Text style={styles.followUpQuestion}>{question}</Text>

      <TextInput
        style={styles.input}
        multiline
        placeholder="Your answer..."
        value={answer}
        onChangeText={setAnswer}

        style={[styles.submitButton, submitting && styles.buttonDisabled]}
        onPress={submitAnswer}
        disabled={submitting}
      >
        <Text style={styles.submitButtonText}>
          {submitting ? 'Saving...' : 'Save Answer'}
        </Text>
      </TouchableOpacity>
