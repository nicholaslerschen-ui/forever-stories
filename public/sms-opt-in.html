Forever Stories - SMS Opt-In / Call to Action Flow

This page documents the complete SMS opt-in process within the Forever Stories mobile app. SMS messages are only sent when an existing user explicitly initiates an invitation to a family member.

Key Points:
  • SMS is user-initiated only - a logged-in user must actively choose to send an invite via text message
  • Each recipient receives only one SMS per invitation - no recurring messages
  • Clear consent disclosure is shown before the user sends the invite
  • Recipients can reply STOP to opt out at any time

Step-by-Step SMS Opt-In Flow

1 User Navigates to Invite Screen

A logged-in user taps "Invite Loved One" from the app's main menu or settings. This is a deliberate action that requires authentication.

2 User Selects SMS as Delivery Method

Send Invite

The user manually enters the recipient's phone number. Before tapping "Send Invite", the following consent disclosure is displayed:

"By sending this invite, the recipient will receive an SMS message from Forever Stories with an invite code. Message and data rates may apply. Recipients can reply STOP to opt out. See our SMS Terms and Privacy Policy at www.foreverstories.co/sms-terms"
4 SMS Message is Sent

After tapping "Send Invite", a single SMS message is delivered to the recipient. The message contains:

Example SMS:
"John Smith has invited you to Forever Stories! Your invite code: ABC12345. Download the app and enter this code to view their stories. Expires in 30 days. Reply STOP to opt out. Msg & data rates may apply."

This is a one-time message. No follow-up or recurring messages are sent.

5 Opt-Out Mechanism

Recipients can reply STOP to immediately opt out of any future messages. They can also reply HELP for assistance.
