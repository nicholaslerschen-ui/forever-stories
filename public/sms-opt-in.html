Forever Stories - SMS Opt-In / Call to Action Flow

This page documents the complete SMS opt-in process within the Forever Stories mobile app. SMS messages are only sent when an existing user explicitly initiates an invitation to a family member.

Key Points:
  • SMS is user-initiated only - a logged-in user must actively choose to send an invite via text message
  • Each recipient receives only one SMS per invitation - no recurring messages
  • Clear consent disclosure is shown before the user sends the invite
  • Recipients can reply STOP to opt out at any time

Step-by-Step SMS Opt-In Flow

1 User Navigates to Invite Screen

A logged-in user taps "Loved Ones Access" from the app's settings. This is a deliberate action that requires authentication. The default delivery method is Email.

Screenshot: Invite screen with Email selected as default delivery method
2 User Selects SMS as Delivery Method and Enters Phone Number
Screenshot: User selects "Text Message" and enters the recipient's phone number

The user actively selects "Text Message" as the delivery method (email is the default). This is a conscious choice by the user. The user then manually enters the recipient's phone number.

3 Consent Disclosure Shown Before Sending
Screenshot: Consent disclosure text displayed above the "Send via Text" button

Before tapping "Send via Text", the following consent disclosure is clearly displayed on screen:

"By sending this invite, the recipient will receive an SMS message from Forever Stories with an invite code. Message and data rates may apply. Recipients can reply STOP to opt out. See our SMS Terms and Privacy Policy at www.foreverstories.co/sms-terms"

This disclosure includes: brand name (Forever Stories), message purpose (invite code), data rates notice, STOP opt-out instructions, and a link to SMS Terms and Privacy Policy.

4 SMS Message is Sent (One-Time)
Screenshot: Confirmation dialog after SMS invitation is sent

After tapping "Send via Text", a single SMS message is delivered to the recipient. A confirmation dialog is shown. The SMS message contains:

Example SMS:
"[Sender Name] has invited you to Forever Stories! Your invite code: [CODE]. Download the app and enter this code to view their stories. Expires in 30 days. Reply STOP to opt out. Msg & data rates may apply."

This is a one-time message. No follow-up or recurring messages are sent.

5 Opt-Out Mechanism

Recipients can reply STOP to immediately opt out of any future messages. They can also reply HELP for assistance.
